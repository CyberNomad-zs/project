# 字段映射字典

> 版本：v1.0 · 2026-07-27  
> 用途：采集 payload ↔ 中心表 ↔ 飞书多维表 三方对齐

---

## 1. 约定

| 项 | 规则 |
|----|------|
| 时间 | 一律存 UTC；展示转 `Asia/Shanghai` |
| 金额 | `NUMERIC(18,4)` + `currency`（默认店铺币种） |
| 业务日 | `biz_date` = DATE，广告/销售类默认 **昨日** |
| 平台枚举 | `amazon` / `tiktok` / `temu` / `other` |
| 幂等键 | `{source}:{shop_id}:{biz_id}:{biz_date}[:extra]` |
| 空值 | 采集不到传 `null`，不传字符串 `"N/A"` |
