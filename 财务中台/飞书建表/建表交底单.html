03

现金流对接 复用现有 +补

汇率 & 流水 —— 复用，不新建

  • 折算引用 每月1号汇率记录（美元/英镑/欧元/港元汇率），按月关联 Lookup
  • 账户流水复用 日记账；本月结存取各日记账当月末 账户余额 汇总
账户余额CNY = ROUND( {CNY}+{CNH} + {USD}*{美元汇率} + {GBP}*{英镑汇率} + {EUR}*{欧元汇率} + {HKD}*{港元汇率}, 2 ) # 无日元

合同表 —— 补字段 新建字段/子表

  • 合同表加：收付方向（单选 应收/应付）、币种（单选）
  • 新建 合同收付计划 子表：关联合同 · 期数 · 金额 · 币种 · 到期日 · 状态（未收付/已收付）——分期应收应付都进这里

月度资金报表 —— 新建

左侧账户结存（关联日记账/头寸）；右侧资产负债块手填（押款/FBA货值/应付货盘/应付运费）；勾稽：

勾稽差异 = ROUND( SUM(账户折算CNY) − SUM(本月结存), 2 ) # ≠0 标红 现金缺口 = 现金合计 − Σ应付(合同收付计划 应付,到期≤窗口) − 应付货盘/运费 + Σ应收(合同收付计划 应收 + 未开发票) # <阈值 标红

边际利润表 新建宽表

一行 = 月份×平台×店铺×站点（预留SKU）。维度里「店铺」关联 §01 主数据映射表。科目明细做数字录入列，利润桥做公式字段。

# 汇总 净销售量 = {销售量}-{退款量} 经营销售 = {销售额}-{促销折扣} 经营退款 = {销售退款}+{退款损失} 经营收入 = {经营销售}-{经营退款} 平台费用 = {佣金}+{广告}+{推广费}+{尾程配送}+{仓租}+{销毁费}+{移除费}+{平台罚款}+{退货费} 成本合计 = {采购成本}+{头程成本} # 其他项目（已确认口径：收入/利润=加，费用/罚款=减） 其他项目 = {其他收入}+{退税收入}+{税金收入}+{情趣利润}+{黑猫利润} - {其他支出}-{提款手续费}-{中转费}-{操作费}-{快递罚款} # 利润桥（重建自 #REF!） 毛利率 = IF({经营收入}=0,"", 1-{成本合计}/{经营收入}) 边界利润 = {经营收入}-{税费}-{平台费用}-{成本合计}+{其他项目} 边界利润率 = IF({经营收入}=0,"", {边界利润}/{经营收入})
