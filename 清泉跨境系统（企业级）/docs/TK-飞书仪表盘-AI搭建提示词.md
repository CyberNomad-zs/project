### 硬性口径（每段提示词都会强调）

| 项 | 错误 | 正确 |
|----|------|------|
| 整体 ROI | 多行 ROI / 广告ROI 直接平均 | Σ销售额 ÷ Σ花费（或只看单日） |
| 多币种 | 店 GMV(GBP 等) + 广告(USD) 无脑加总 | 靠「店铺」筛选；币种分列 |

## 1. D1 · 多店对比（复制整段）

```text
请基于本多维表格，新建一页仪表盘，名称：D1 多店对比。

【数据源】只使用表「店铺日经营」，不要用其他表。

【全局筛选器】
1. 日期范围 → 字段「日期」
2. 店铺 → 字段「店铺」

【顶部数字卡，横排 5 个】
1. 周期销售额：指标「销售额」求和
2. 周期订单量：指标「订单量」求和
3. 周期广告花费：指标「广告花费」求和
4. 整体广告ROI：不要对「广告ROI」列求平均；请用「广告销售额求和 ÷ 广告花费求和」计算；若系统不支持除法卡，则改为展示单日「广告ROI」
5. 平均健康分：指标「健康分」平均值（有值时）

【中部图表】
1. 条形图「各店销售额对比」
   - 维度：店铺
   - 指标：销售额 · 求和
   - 排序：销售额降序
2. 条形图「各店广告花费对比」
   - 维度：店铺
   - 指标：广告花费 · 求和
   - 排序：广告花费降序
3. 折线图「近30天销售额趋势」
   - 维度：日期
   - 指标：销售额 · 求和
   - 如支持系列/分组：按店铺拆线
4. 折线图「近30天广告花费趋势」
   - 维度：日期
   - 指标：广告花费 · 求和
   - 如支持系列/分组：按店铺拆线

【底部数据表】
- 组件类型：数据表 / 明细表
- 优先绑定视图「昨日全店」；若无该视图，则筛选日期=昨天，按销售额降序
- 展示字段：日期、店铺、销售额、订单量、广告花费、广告销售额、广告ROI、健康分、结算金额、币种、广告币种

【重要口径】
- 金额字段不要跨币种无脑加总；默认靠「店铺」筛选看单店
- 「广告ROI」是率类指标，禁止多行直接平均
- 不要绑定已砍的 AI 素材表或旧广告日报表
```

**布局示意：**

```
┌─────────────────────────────────────────────────────────┐
│ 筛选：日期范围 | 店铺                                       │
├──────────┬──────────┬──────────┬──────────┬─────────────┤
│ 销售额    │ 订单量    │ 广告花费  │ 广告ROI*  │ 健康分(均)   │
├──────────┴──────────┴──────────┴──────────┴─────────────┤
│ 各店销售额条形          │ 各店广告花费条形                    │
├─────────────────────────┴───────────────────────────────┤
│ 近30天 GMV 折线（可按店拆线）│ 近30天广告花费折线             │
├─────────────────────────────────────────────────────────┤
│ 昨日全店对比表：销售、订单、花费、ROI、健康、结算、币种        │
└─────────────────────────────────────────────────────────┘
```

## 2. D2 · 广告投放（复制整段）

```text
请基于本多维表格，新建一页仪表盘，名称：D2 广告投放。

【数据源】
- 顶部汇总数字卡：优先用「广告活动日明细」；店级补充可用「店铺日经营」
- 明细图表与表格：只用「广告活动日明细」
- 可选：再挂一张「异常任务」未闭环列表
- 不要使用旧表「TK广告日报」，不要使用「AI广告智能筛选分析表」

【全局筛选器】
1. 日期范围 → 「日期」
2. 店铺 → 「店铺」

【顶部数字卡，横排 4～5 个】
1. 周期广告总花费：「广告活动日明细」·「广告花费」求和
2. 周期广告销售额：「广告活动日明细」·「销售额」求和
3. 周期广告订单/销量：「广告活动日明细」·「销量」求和
4. 整体ROI：不要对「ROI」列求平均；用「销售额求和 ÷ 广告花费求和」；不支持则改展示「店铺日经营」单日「广告ROI」
5. 未闭环异常数（可选）：「异常任务」记录数，筛选状态=未处理或处理中

【中部图表】
1. 条形图「活动花费 TOP」
   - 表：广告活动日明细
   - 维度：品名
   - 指标：广告花费 · 求和
   - 排序：花费降序，取 Top10 或 Top20
2. 条形图或饼图「盈亏标签分布」
   - 维度：盈亏标签
   - 指标：记录数 计数；如可再加一图：广告花费求和
3. 条形图「预算将尽活动」（可选）
   - 筛选：预算消耗率 > 0.8
   - 维度：品名
   - 指标：预算消耗率 或 广告花费

【右侧/下部数据表】
1. 数据表「低效亏损活动」
   - 绑定视图「低效亏损」；若无，则筛选 盈亏标签=低效亏损，按广告花费降序
   - 字段：日期、店铺、品名、广告花费、销售额、销量、ROI、日预算、预算消耗率、盈亏标签、计划状态
2. 数据表「高ROI活动」
   - 绑定视图「高ROI」；若无，则筛选 盈亏标签=高ROI，按 ROI 或 销售额降序
   - 字段同上
3. 数据表「异常任务-广告相关」（可选）
   - 表：异常任务
   - 筛选：状态=未处理/处理中；异常类型或异常码包含广告/ads
   - 字段：优先级、状态、异常类型、摘要、店铺、创建时间

【条件强调】
- 盈亏标签=低效亏损 标红；=高ROI 标绿
- ROI < 3 可标红
- 汇总时不要把名称像「【店铺汇总】」这类汇总行再加一遍（若表里还有）
- ROI/预算消耗率都是率，禁止多行直接平均
```

**布局示意：**

```
┌─────────────────────────────────────────────────────────┐
│ 筛选：日期 | 店铺                                          │
├──────────┬──────────┬──────────┬──────────┬─────────────┤
│ 广告花费  │ 广告销售  │ 广告订单  │ 整体ROI* │ 未闭环异常   │
├───────────────────────┬─────────────────────────────────┤
│ 活动花费 TOP 条形      │ 盈亏标签分布（饼/条）              │
├───────────────────────┴─────────────────────────────────┤
│ 低效亏损表 │ 高ROI表 │（可选）异常任务-广告相关              │
└─────────────────────────────────────────────────────────┘
```

## 3. D3 · 视频内容（复制整段 · 现网页名；旧文 D4）

> 若页已存在且名称是「D3 视频内容」，只需验收/修坏卡，不必再建。

```text
请基于本多维表格，新建一页仪表盘，名称：D3 视频内容。

【数据源】只使用表「内容日」；异常列表可用「异常任务」。
不要绑定「店铺日经营」「广告活动日明细」「AI广告智能筛选分析表」「达人日」。

【重要口径】
- 「日期」是窗口锚点日，不是把近7天拆成7行
- 「窗口」字段例如「最近 7 天」表示该行已是窗口快照
- 同一内容不要跨多个窗口锚点混加；筛选时先固定一个日期/窗口再看汇总
- 不要对窗口内数字再除以 7

【全局筛选器】
1. 日期（锚点）→ 「日期」
2. 店铺 → 「店铺」
3. 渠道 → 「渠道」（如有）

【顶部数字卡】
1. 归因GMV合计：「归因GMV」求和
2. 播放量合计：「播放量」求和
3. 曝光合计：「曝光」求和
4. 归因订单合计：「归因SKU订单」求和
5. 有曝无单条数（可选）：筛选 曝光≥200（或播放量≥200）且 归因GMV=0 且 归因SKU订单=0 后的记录数

【中部图表】
1. 条形图「归因GMV TOP 视频」
   - 维度：视频标题（若空则用内容ID）
   - 指标：归因GMV · 求和
   - 排序：降序，Top10
2. 条形图「高播放视频」
   - 维度：视频标题或内容ID
   - 指标：播放量 · 求和
   - 排序：降序，Top10
3. 如支持，可再做一个「渠道分布」：维度=渠道，指标=播放量或归因GMV

【下部数据表】
1. 「有曝无单」
   - 绑定视图「有曝无单」；若无，则筛选：曝光≥200（或播放≥200）且 归因GMV=0 且 归因SKU订单=0
   - 字段：日期、店铺、内容ID、视频标题、渠道、播放量、曝光、点击、归因GMV、归因SKU订单、窗口
2. 「归因GMV Top」
   - 筛选 归因GMV > 0，按归因GMV 降序
   - 字段同上，可加 CTR、CVR、客户数
3. 「视频异常任务」（可选）
   - 表：异常任务
   - 筛选：异常类型包含「视频」或对象类型包含 content/视频
   - 字段：优先级、状态、异常类型、摘要、店铺

【不要做】
- 不要绑定已砍的 AI 素材表，不要出现 S/A/B/C/D 分级卡
- 不要把内容日数据当成按自然日可加总的日流水
```

**布局示意：**

```
┌─────────────────────────────────────────────────────────┐
│ 筛选：日期(锚点) | 店铺 | 渠道                             │
├──────────┬──────────┬──────────┬──────────┬─────────────┤
│ 归因GMV  │ 播放量    │ 曝光     │ 归因订单  │ 有曝无单数   │
├───────────────────────┬─────────────────────────────────┤
│ 归因GMV TOP 条形       │ 高播放 TOP 条形 / 渠道分布         │
├───────────────────────┴─────────────────────────────────┤
│ 有曝无单表 │ 归因GMV Top 表 │（可选）视频异常任务            │
└─────────────────────────────────────────────────────────┘
```

## 4. D4 · 联盟达人（复制整段 · 现网页名；旧文 D5）

```text
请基于本多维表格，新建一页仪表盘，名称：D4 联盟达人。

【数据源】只使用表「达人日」；异常列表可用「异常任务」。
不要绑定「店铺日经营」「广告活动日明细」「内容日」「AI广告智能筛选分析表」。
禁止用广告花费/广告销售额冒充达人投入或达人 GMV。

【重要口径】
- 「日期」是窗口锚点日；「窗口」如「近 7 天」表示该行已是窗口快照
- 不要对窗口数字再除以 7，不要拆成 7 行日流水
- 投入相关：只有「预计佣金」有数；没有达人投流花费、寄样金额列时不要做数字卡，不要填 0
- 达人归因 GMV ≠ 店日 GMV ≠ 广告花费，三者不可加总

【全局筛选器】
1. 日期（锚点）→ 「日期」
2. 店铺 → 「店铺」

【顶部数字卡】
1. 达人归因GMV合计：对「达人归因GMV」或表内等价 GMV 字段求和
2. 成交件数合计：有则求和
3. 预计佣金合计：有则求和
4. 达人行数或动销相关：有「是否出单」则计数出单行；否则显示记录数
5. 不要做「投流花费」「寄样金额」卡

【中部图表】
1. 条形图「达人归因GMV TOP」
   - 维度：达人名称或达人ID/handle
   - 指标：达人归因GMV · 求和
   - 排序：降序 Top10
2. 条形图「预计佣金 TOP」（可选）
   - 维度：同上
   - 指标：预计佣金 · 求和

【下部数据表】
1. 达人明细：日期、店铺、达人、handle/ID、归因GMV、成交件、订单、预计佣金、退款、视频数、窗口
2. 「达人异常任务」（可选）：异常任务表，筛选达人表现 / creator / 异常码含 creator_

【不要做】
- 不要出现 AI 素材 S/A/B/C/D
- 不要把 T2 广告花费拖进本页
- 不要把未采的投流/寄样显示成 0
```

## 7. 搭完后验收

| # | 检查项 | 期望 |
|---|--------|------|
| 1 | 无「配置数据发生变更，请重新配置」 | 有则按重绑清单逐卡修 |
| 2 | D1 只出现 T1 字段 | 无 AI 评级 / 无旧日报列名 |
| 3 | D2 明细来自 T2「品名/销售额/盈亏标签」 | 非旧插件列布局 |
| 4 | ROI 数字卡 | **不是**对 ROI 列直接平均 |
| 5 | D3 筛选先固定锚点日/窗口 | 跨窗数字未混加、未 /7 |
| 6 | D4 只绑达人日 | 无 T2 spend；无投流/寄样假 0 |
| 7 | AI 素材 | **无**绑 `AI广告智能筛选分析表` 的组件 |

### 坏卡片怎么修（约 10～15 分钟）

1. 点卡片 **… → 编辑**（或「重新配置」）
2. **数据源** 改回上文推荐表
3. 维度/指标按提示词同名字段重选
4. 保存后刷新仪表盘

全局筛选器：日期 →「日期」；店铺 →「店铺」或「店铺ID」。

更细的重绑映射见：[TK-飞书驾驶舱-仪表盘重绑清单](./TK-飞书驾驶舱-仪表盘重绑清单.md)。
