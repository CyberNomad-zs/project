## 采集 dual 上报

TK 副本配置（本机、勿提交密钥）：

- 文件：`collectors/tiktok-ads/config/stores.config.json`
- `qingquan.baseUrl` = `https://qingquan.jmzlai.com`
- `qingquan.source` = `tiktok_ads`
- `feishu.writeMode` = `dual`（飞书 + 清泉）
- **`qingquan.apiKey` 必须等于服务器 `/opt/qingquan/.env` 的 `INGEST_DEFAULT_API_KEY`**  
  - 默认仓库里的 `dev-ingest-key` **只适用于本地**；生产已轮换，填错会 401  
  - 查生产密钥：`ssh qingquan-sg "grep INGEST_DEFAULT_API_KEY /opt/qingquan/.env"`

本地开发仍可用 `http://127.0.0.1:8000` + `scripts/start-api.ps1`。

### 点测上报

```powershell
cd collectors\tiktok-ads
# 需已有 logs\scrape-debug-last.json，或先跑 multi-store 抓一店
powershell -ExecutionPolicy Bypass -File .\logs\_repost_last.ps1
# 或手工：
. .\scripts\qingquan-client.ps1
# ... ConvertTo-QingquanIngestItems + Send-QingquanIngest
```

成功时应见 `accepted>0`；重复上报同日同计划为 `duplicated`。
