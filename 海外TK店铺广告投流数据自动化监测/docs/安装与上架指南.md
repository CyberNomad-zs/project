# 安装与上架指南（紫鸟卖家自研插件）

官方说明入口：[紫鸟开放平台文档](https://open.ziniao.com/docSupport?docId=101)

## A. 开发调试（推荐先做）

1. 登录紫鸟浏览器，**打开任一已绑定设备的店铺窗口**（需能访问 `chrome://extensions/`）。
2. 地址栏打开：`chrome://extensions/`
3. 开启右上角 **开发者模式**。
4. **加载已解压的扩展程序** → 选择本仓库目录：
   ```
   ...\海外TK店铺广告投流数据自动化监测\extension
   ```
5. 在店铺窗口打开 TikTok 广告系列/报表列表页。
6. 点击扩展图标 → 打开 **设置** 填写飞书凭证 → 返回 Popup 勾选「干跑」→ **立即抓取**。

参考文档菜单：接入指南 → 卖家自研插件 → 谷歌插件开发调试教程。

## B. 打包 ZIP

在项目根目录 PowerShell 执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\package-zip.ps1
```

产物：`dist/tk-ad-scraper-v{version}.zip`  
**要求**：ZIP 解压后根目录直接可见 `manifest.json`（脚本已保证）。

也可手动：在 `extension` 文件夹内全选文件 → 压缩为 zip（不要多包一层 `extension` 文件夹）。

## C. 上架卖家自研插件

1. 使用 **Boss / 已授权企业内部开发者** 登录 [紫鸟开放平台](https://open.ziniao.com/)。
2. 开发者控制台 → 创建 **卖家自研插件**。
3. 版本管理 → 上传插件包（ZIP/CRX）→ 填写类目与基本信息 → 发布。
4. 卖家自研插件一般 **无需公开审核**，提交后可企业内部使用。

## D. 分配给店铺账号

1. 紫鸟浏览器 → **管理 → 应用管理**。
2. 找到本插件卡片 → **配置** → **分配账号**。
3. 勾选 3 个英区 TikTok 店铺账号 → 确认。
4. 使用人需具备相应「添加插件 / 应用管理」角色权限（按公司权限模型配置）。

专业版白名单：见开放平台文档  
「紫鸟浏览器专业版如何安装插件及设置员工白名单（v5/v6）」。

## E. 定时抓取注意

- Popup/设置中可开启每日定时（默认中国 17:20；业务日按英国时区）。
- **限制**：定时触发时紫鸟进程需在运行，且店铺环境中最好已有可抓取的广告页；扩展无法在关机状态下自行登录店铺。
- 完全无人值守：二期可用 Windows 任务计划 + `ziniao-cli store open` 先拉起店铺窗口。
