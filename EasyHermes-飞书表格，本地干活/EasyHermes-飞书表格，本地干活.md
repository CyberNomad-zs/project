EasyHermes 定位为企业 AI 中台——不只是一个聊天工具，而是一个能操作本地文件、连接飞书云、驱动硬件设备、自动化业务流程的 AI Agent 平台。它把大模型的能力从「对话」延伸到了「干活」：写 Word、做 PPT、处理 Excel、收发邮件、搭建飞书多维表格、采集网页数据、管理客户信息，全部通过自然语言指令完成。

## 常见问题

**Q: exe 双击后没有反应？**

检查是否被杀毒软件拦截。添加到白名单即可。如果仍然没有反应，尝试右键「以管理员身份运行」。

**Q: 浏览器没自动打开？**

手动打开浏览器，访问 http://localhost:7777。如果页面空白，等待 10\-30 秒后刷新。

**Q: AI 回复乱码？**

重启 exe 即可。如果持续出现，确认 Windows 系统语言是中文。

**Q: 终端命令执行失败？**

安装 Git for Windows（git\-scm\.com）后重启 EasyHermes。不装也能用基础命令。

**Q: 如何用自己的 API Key？**

编辑 workspace/config\.yaml，添加你自己的 provider 配置。

**Q: 如何备份数据？**

整个 EasyHermes/ 文件夹复制到其他地方即可。所有数据都在 workspace/ 里。

**Q: 硬件宠物怎么接入？**

需要有 ESP32\-S3 开发板 \+ 烧录配套固件。在 Dashboard 的 AI 硬件页面配置 IP 地址即可。

**Q: Token 额度用完了怎么办？**

两种方案：① 在平台续费充值内置 Token；② 配置外置模型（如 DeepSeek，5\-10 块钱能用很久）。

**Q: 多人使用怎么办？**

设置 WEB\_HOST=0\.0\.0\.0 后，同一局域网内的设备都可以通过浏览器访问。

**Q: 数据安全吗？**

所有数据存储在本地 workspace/ 目录下，不上传到任何云端。

**Q: 如何更新到新版本？**

备份 workspace/ → 下载新版本 → 替换 exe → 重启。workspace/ 不会被覆盖。
