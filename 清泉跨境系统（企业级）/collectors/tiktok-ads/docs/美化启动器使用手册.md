# 美化启动器使用手册（整站采集版）

> 适用对象：负责 **TK 广告日报 + 整站经营采集** 的运营 / 采集机同学  
> 工具文件：`collectors/tiktok-ads/美化启动器.bat`（图形界面）  
> 备选：同目录 `启动器.bat`（黑窗口菜单，不依赖 Python GUI）  
> **交接一页纸（发微信/飞书用）：** [运营交接一页纸.md](./运营交接一页纸.md)  
> 调度说明：[TK-采集调度划分计划.md](./TK-采集调度划分计划.md) · [每日定时任务.md](./每日定时任务.md)

---

## 1. 这个工具是做什么的？

深色图形窗口，一键调用本目录采集脚本：

| 能力 | 说明 |
|------|------|
| **广告日报** | 预览店 / 干跑 / 立即日报 / 安装 **17:20** 任务（与旧广告启动器一致） |
| **夜间整站立即跑** | 店 KPI、订单、商品、内容+商品卡、联盟达人、full-site 合并链 |
| **规则 + 飞书** | 仓库根 `tk-p0-post-collect`（不抢紫鸟）；默认定时 **21:00** |
| **装计划任务** | 一键装夜间拆分包（19:45–20:55）+ 21:00 尾巴 |
| **白天轮巡** | `night-loop -SkipAds`（需手动停止） |
| **查日志/配置** | `logs\`、`config\stores.config.json`、`日报\` |

数据主路径：**紫鸟 → 清泉 Ingest → PostgreSQL**；飞书经 post-collect / sync，不长期直写绕过 PG（广告日报历史链路可仍写飞书）。

## 2. 每天开跑前请确认

| # | 检查项 | 怎么确认 |
|---|--------|----------|
| 1 | Windows 已登录 | 桌面会话（注销/关机不行） |
| 2 | 紫鸟客户端已打开并登录 | 能看到店铺列表；Bridge `127.0.0.1:9481` |
| 3 | `config\stores.config.json` 存在且 `qingquan.enabled` | 点「打开配置」 |
| 4 | 本机 Python 3（仅图形界面） | 双击美化启动器能出窗 |
| 5 | Node + ziniao-cli | 「环境自检」 |
| 6 | 规则/飞书：能连 PG + `FEISHU_*` | 中心机或本机已配仓库根 `.env` |

## 3. 如何打开

1. 进入 `collectors\tiktok-ads`（或桌面快捷方式指向该目录）。  
2. **双击** `美化启动器.bat`。  
3. 出现标题 **「TK 整站采集 · 启动器」**。

| 现象 | 处理 |
|------|------|
| 提示找不到 Python | 安装 Python 3 并勾选 PATH；或改用 `启动器.bat` |
| 提示找不到 `gui.py` | 必须在完整项目目录双击，不要只拷 bat |
| 只要控制台 | 用 `启动器.bat` |

## 4. 界面分区

```
┌ 标题栏（固定）
│ 广告日报 / 夜间整站 / 中心尾巴 / 安装 / 其它   ← 按钮区可滚轮下滑
├ 运行输出（固定高度，自带滚动）
├ 状态行（固定）
└ 路径脚注（固定）
```

- **按钮区**在中间：鼠标移入后用滚轮上下滑，可看到最底下的「其它」。  
- **同一时间只能跑一个任务**；冲突时先「停止当前任务」。  
- 失败日志：`logs\gui-*.log`。

### 推荐默认时刻（安装任务时写入）

| 任务 | 时刻 |
|------|------|
| 广告日报 | **17:20**（不动） |
| Shop / Orders / Products | **19:45 / 20:00 / 20:20** |
| Content / Affiliate | **20:40 / 20:55** |
| 规则+飞书 | **21:00** |

## 5. 按钮怎么用（精简）

### 广告

| 按钮 | 何时用 |
|------|--------|
| 预览店铺 | 正式跑前核对名单 |
| 干跑 | 验证流程、不写飞书 |
| 立即日报 | 漏跑补数（同 17:20） |
| 安装 17:20 | 同事机/本机装广告任务 |

### 整站立即跑

| 按钮 | 脚本 |
|------|------|
| 店 KPI… | `run-shop-modules-daily.ps1` |
| 订单 / 商品 | `run-orders-daily` / `run-products-daily` |
| 内容+商品卡 | `run-content-daily`（强制入库） |
| 联盟达人 | `run-affiliate-daily`（含 Pop） |
| full-site | shop→orders→products；**勿与拆分任务高峰双开** |

### 中心 / 安装

| 按钮 | 说明 |
|------|------|
| 规则+飞书 | 仓库根 post-collect；需库+飞书 |
| 安装夜间拆分任务包 | 一次装 5 个 schtasks |
| 安装 21:00 规则飞书 | 中心机常用 |
| 白天空闲轮巡 | SkipAds，**记得停**，避开 17:20 |

## 6. 与旧「仅广告」启动器的关系

| 项目 | 路径 |
|------|------|
| 旧独立广告工程 | `E:\project\海外TK店铺广告投流数据自动化监测\美化启动器.bat` |
| 清泉仓库整站版 | `清泉跨境系统（企业级）\collectors\tiktok-ads\美化启动器.bat` |

界面风格一致（深色 tkinter）；清泉版在广告能力上扩展了整站与 post-collect。广告 17:20 仍可只在同事机跑，本启动器用于采集机整站 + 补跑。
