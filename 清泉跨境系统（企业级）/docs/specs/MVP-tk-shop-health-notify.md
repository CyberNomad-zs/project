## Spec 引用与目标复述

**目标（一句话）：**  
全 `stores.config` TK 店：账号健康 / 体验分（含三模块）/ 达人健康多账号 / 1–2★ 差评 / 达人新违规 → PG；任意变差或新增则 **群机器人 + App 私信宋敏**；体验分三模块进 **现有 TK 驾驶舱 Base 新表**。

**In Scope P0 全集**见 Spec §2.1；本 MVP 不扩 Out of Scope。

---

## Ship-now（本迭代必做，5 条）

| # | 能力 | Spec In Scope # | 说明 |
|---|------|-----------------|------|
| **M1** | 店铺体验分采集 + 三模块落 PG + 同步飞书新表 | #2 #3 | 新 source/事实表；Base=现有 TK；`table_id` env |
| **M2** | 达人健康评分多账号采集 + 下降/新违规 → 异常任务 | #5 #6 | 切换账号列表全采；达人维度 dedupe |
| **M3** | 飞书企业应用 **私信**通道（配置 App + 宋敏 user_id） | #8 | Secret 仅 env；失败不阻断任务/群 |
| **M4** | 全部本迭代告警规则 **双通道**（群 webhook 保留 + 私信） | #1 #4 #7 #8 | 含健康任意下降/≤150、体验/三模块变差、差评、达人违规 |
| **M5** | 日更纳入全 config 店；单店/单模块失败隔离 | 范围 1B | 扩展 `run-shop-modules*` 或等价调度 |

**刻意不塞进本刀：** 任务台新专页、飞书图表装修、自动申诉/回评。
