# TK 整站采集 · 运营交接一页纸

> 给：采集机 / 运营同学  
> 工具目录：`清泉跨境系统（企业级）\collectors\tiktok-ads\`  
> 详版：[美化启动器使用手册.md](./美化启动器使用手册.md) · [TK-采集调度划分计划.md](./TK-采集调度划分计划.md)

---

## 1. 每天怎么开

| 步骤 | 做什么 |
|------|--------|
| ① | Windows **已登录**（注销/关机不行；锁屏一般可以） |
| ② | **紫鸟**客户端打开并登录（能看到店铺列表） |
| ③ | 双击 **`美化启动器.bat`**（图形界面） |
| ④ | 备选：同目录 **`启动器.bat`**（黑窗口菜单，不依赖 Python） |

---

## 2. 推荐日更时刻（装任务后自动跑）

| 时刻 | 任务 | 谁跑 |
|------|------|------|
| **17:20** | 广告日报 | **同事机**（中心不重复装） |
| **19:45** | 店 KPI / 健康 / 财务 | 采集机 |
| **20:00** | 订单 | 采集机 |
| **20:20** | 商品 | 采集机 |
| **20:40** | 内容 + 商品卡 | 采集机 |
| **20:55** | 联盟达人（含 Pop） | 采集机 |
| **21:00** | 规则 + 飞书同步 | **中心机**（或已配 PG+飞书的机器） |

> 广告 17:20 **不要**和夜间整站抢同一时段紫鸟。  
> 白天若开「空闲轮巡」，**务必避开 17:20**，用完点「停止当前任务」。

---

## 3. 首次上机（只做一次）

1. 确认本目录有 `config\stores.config.json`（可从 `stores.config.example.json` 复制后改；**含密钥勿外传、勿提交 Git**）。  
2. 打开启动器 → **环境自检** 通过。  
3. **广告·预览店铺**，核对会抓哪些店。  
4. 点 **「安装·夜间拆分任务包」**（写入 19:45–20:55）。  
5. 中心机点 **「安装·21:00 规则飞书」**（需能连 PostgreSQL + 飞书）。  
6. 任选一个模块 **立即跑** 试一次（如「整站·商品」），看下方「运行输出」无报错。  
7. 次日看飞书看板 / 任务台数据是否更新。

## 4. 按钮速查（常用）

| 场景 | 点哪个 |
|------|--------|
| 漏跑广告补数 | 广告·立即日报 17:20 |
| 漏跑整站某一块 | 夜间整站区对应按钮（店/订单/商品/内容/联盟） |
| 整晚一条龙（店→单→品） | 整站·合并链 full-site（**勿与拆分任务高峰双开**） |
| 只刷飞书、不抢紫鸟 | 规则+飞书 21:00 或 飞书·仅同步 |
| 查失败原因 | 打开日志目录 → `logs\gui-*.log` / `*-daily-*.log` |
| 卡住 / 要换任务 | **停止当前任务**（同时只跑一个） |

---

## 5. 出问题先看这 5 条

| 现象 | 处理 |
|------|------|
| 启动器打不开 | 装 Python 3 并勾选 PATH；或改用 `启动器.bat` |
| 连不上店 / Bridge | 紫鸟是否登录；本机 `127.0.0.1:9481` |
| 计划任务没跑 | 任务计划程序里看 `TK-*` 是否 **Ready**（不是 Disabled）；时间是否已是上表 |
| 飞书没数 | 采集是否已入库；21:00 规则飞书是否在中心机跑成功 |
| 广告和整站互相打断 | 确认 17:20 只在同事机；采集机夜间任务 ≥19:45 |

---

## 6. 责任边界（避免扯皮）

| 事项 | 负责 |
|------|------|
| 广告 17:20 日更是否跑稳 | **同事机** + 广告侧文档 |
| 夜间整站采集是否跑稳 | **采集机**运营 / 装机人 |
| 规则计算 + 飞书驾驶舱同步 | **中心机**（PG + `FEISHU_*`） |
| Ingest API / 数据库可写 | 研发 / 中心服务 |
| 改抓取字段、修脚本 | 研发（本仓库） |

## 7. 相关路径（复制用）

```text
collectors\tiktok-ads\
  美化启动器.bat          ← 日常入口
  启动器.bat              ← 无 GUI 备选
  config\stores.config.json
  logs\                   ← 出问题先看这里
  日报\                   ← 广告日报产出（若启用）
  docs\美化启动器使用手册.md
  docs\TK-采集调度划分计划.md
  docs\每日定时任务.md

仓库根 scripts\
  tk-p0-post-collect.ps1
  feishu-tk-daily-sync.ps1
```

---

**一句话：** 紫鸟开着 → 双击美化启动器 → 夜间任务 19:45 起自动采 → 21:00 中心算规则推飞书；广告 17:20 仍在同事机。
