## 0. 定位

异常任务表是**人维任务台**，不是数据看板：核心不是「卖了多少」，而是「还有多少没闭环、谁负责、哪些反复出现、哪些要老板拍板」。因此本页一切指标以 **状态 + 优先级 + 连续异常次数** 为主线，**不对金额/数值类字段跨异常类型加总**。

## 3. 硬性口径（每段提示词都会强调）

| 项 | 错误 | 正确 |
|----|------|------|
| 未闭环 | 只数「未处理」 | 「未处理」+「处理中」都算未闭环 |
| P0 vs 老板决策 | 把「P0」当「需要老板决策」 | 两个独立字段，各数各的；通常 P0 会被标老板决策，但以勾选字段为准 |
| 连续异常次数 | 把默认 1 当「高频」 | 只把 ≥2 当反复异常 |
| 金额/数值 | 跨异常类型把「当前值/变化幅度」无脑求和（库存件数 + ROI 率 + GMV 金额） | 只做计数与分布；数值卡只对单一类型/单一字段看 |
| 率类 | 对「变化幅度」直接平均 | 变化幅度是环比%，禁止多行平均 |

## 4. D5 · 异常任务台（复制整段）

```text
请基于本多维表格，新建一页仪表盘，名称：D5 异常任务台。

【数据源】只使用表「异常任务」，不要绑定「店铺日经营」「广告活动日明细」「内容日」「达人日」「AI广告智能筛选分析表」「TK广告日报」。

【全局筛选器】
1. 日期范围 → 字段「日期」
2. 店铺 → 字段「店铺」
3. 状态 → 字段「状态」（多选：未处理、处理中、已闭环、已取消、忽略）
4. 优先级 → 字段「优先级」（多选：P0、P1、P2）

【重要口径】
- 「未闭环」= 状态 = 未处理 或 处理中
- 「优先级 P0」与「需要老板决策」是两个独立字段，不要混用
- 「连续异常次数」默认是 1；只有 ≥2 才算反复异常
- 不要跨异常类型对「当前值」「变化幅度」求和或平均（库存件数、ROI 率、GMV 金额含义不同）
- 「变化幅度」是率类，禁止多行直接平均

【顶部数字卡，横排 5 个】
1. 未闭环异常数：指标「异常编号」计数（或记录数），筛选 状态=未处理 或 处理中
2. P0 异常数：指标记录数，筛选 优先级=P0 且 状态=未处理/处理中
3. 需老板决策数：指标记录数，筛选 需要老板决策=勾选 且 状态=未处理/处理中
4. 反复异常数：指标记录数，筛选 连续异常次数≥2 且 状态=未处理/处理中
5. 已闭环数：指标记录数，筛选 状态=已闭环

【中部图表】
1. 条形图「各店未闭环异常」
   - 维度：店铺
   - 指标：记录数 · 计数
   - 筛选：状态=未处理/处理中
   - 排序：计数降序
2. 条形图或饼图「异常类型分布」
   - 维度：异常类型
   - 指标：记录数 · 计数
   - 筛选：状态=未处理/处理中
   - 排序：计数降序，取 Top10 或 Top20
3. 饼图「优先级分布」
   - 维度：优先级
   - 指标：记录数 · 计数
   - 筛选：状态=未处理/处理中
4. 条形图「反复异常 TOP」
   - 维度：摘要（或产品；空则用异常编号）
   - 指标：连续异常次数 · 最大值
   - 筛选：连续异常次数≥2 且 状态=未处理/处理中
   - 排序：连续异常次数降序，取 Top10

【下部数据表】
1. 数据表「未闭环明细」
   - 表：异常任务
   - 筛选：状态=未处理/处理中
   - 排序：优先级升序（P0 在前），再按日期降序
   - 字段：优先级、状态、异常类型、摘要、店铺、产品、连续异常次数、需要老板决策、负责人、说明、复查日期
2. 数据表「需老板决策」
   - 筛选：需要老板决策=勾选 且 状态=未处理/处理中
   - 字段：优先级、异常类型、摘要、店铺、连续异常次数、负责人、说明、截止时间
3. 数据表「反复异常」
   - 筛选：连续异常次数≥2 且 状态=未处理/处理中
   - 排序：连续异常次数降序
   - 字段：摘要、异常类型、店铺、连续异常次数、当前值、当前值含义、变化幅度、负责人、下一步动作

【条件强调】
- 优先级=P0 标红
- 需要老板决策=勾选 标橙
- 连续异常次数≥2 加粗或标黄
- 状态=已闭环/忽略 置灰

【不要做】
- 不要绑定已砍的 AI 素材表或旧广告日报表
- 不要对「变化幅度」「当前值」跨异常类型求和或平均
```

**布局示意：**

│ 筛选：日期范围 | 店铺 | 状态 | 优先级                        │
├──────────┬──────────┬──────────┬──────────┬─────────────┤
│ 未闭环数  │ P0 数    │ 老板决策  │ 反复异常  │ 已闭环       │
├───────────────────────┬─────────────────────────────────┤

├───────────────────────┴─────────────────────────────────┤

## 5. 怎么用

1. 打开飞书多维表格 → **仪表盘** → 右侧 **多维表格 AI**
2. 能力下拉选 **「仪表盘搭建」**
3. 把第 4 节整段提示词粘贴进输入框发送
4. **一次只建这一页**，避免 AI 混绑其他表的数据源
5. 搭完后按第 6 节验收

---

## 6. 搭完后验收

| # | 检查项 | 期望 |
|---|--------|------|
| 1 | 无「配置数据发生变更，请重新配置」 | 有则点卡片 → 编辑 → 重选异常任务表与字段 |
| 2 | 数据源只出现「异常任务」 | 无 T1/T2/T6/T7 / 旧日报 / AI 素材字段 |
| 3 | 未闭环口径 | 数字卡同时含「未处理」与「处理中」 |
| 4 | P0 与老板决策 | 是两个独立卡，不是同一卡 |
| 5 | 反复异常 | 只筛连续异常次数≥2，不含默认 1 |
| 6 | 数值字段 | 无「当前值求和」「变化幅度平均」这类跨类型卡 |
| 7 | 条件色 | P0 红、老板决策橙、连续≥2 黄 |

### 坏卡片怎么修

1. 点卡片 **… → 编辑**（或「重新配置」）
2. 数据源改回「异常任务」
3. 维度/指标按提示词同名字段重选
4. 保存后刷新仪表盘

全局筛选器：日期 →「日期」；店铺 →「店铺」；状态 →「状态」；优先级 →「优先级」。

## 7. 同步

异常任务表数据来自 PG `tk.fact_tk_anomaly_task`，日常随 TK 飞书同步刷新：

```powershell
# 仓库根
powershell -ExecutionPolicy Bypass -File .\scripts\feishu-tk-daily-sync.ps1 -AnomalyOnly -LookbackDays 30
```
