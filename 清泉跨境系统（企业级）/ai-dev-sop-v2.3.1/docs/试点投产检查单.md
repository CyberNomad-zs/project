# 试点投产检查单

> **状态目标：Pilot-Ready → 有限范围投产**  
> 全部「必须」勾选后，才建议在业务团队宣布启用。  
> 配套：[`试跑剧本.md`](./试跑剧本.md) · [`试跑记录.md`](./试跑记录.md) · `../install.sh`

---

## A. 包与安装（必须）

- [ ] 仓库含 `skills/ai-dev-sop/`、`skill-pack/`、`templates/`、`AGENTS.md`
- [ ] `./install.sh` 或 `./install.sh --check` → **OK**
- [ ] `check-dor.sh` 对 smoke → **PASS**
- [ ] 目标 Agent 客户端可调用 **`/ai-dev-sop`**（用户级或项目级 Skill 链已装）
- [ ] 跨仓读包按 SOP_ROOT；或团队用 `./install.sh --into <业务仓>` 同步包

---

## B. 角色与入口（必须）

- [ ] 已口头/文档同步三层：  
  - 甲方 → `INTENT-raw`  
  - 产品 → `INTENT`  
  - Agent → `/ai-dev-sop`（禁止直接给甲方填专业 INTENT）
- [ ] 团队知道哨兵句与 [`节点交付物.md`](./节点交付物.md)（含 ARCH）
- [ ] 管理者按「节点有进仓文件才算批过」执行
- [ ] G3 清单已同步（资金、密钥、生产数据、法定字段等 → 升级审批）

---

## C. 试跑（必须至少「最小通过」）

- [ ] 已按试跑剧本执行一轮  
- [ ] [`试跑记录.md`](./试跑记录.md) 有对应记录  
- [ ] 结果 ≥ **最小通过**（SPEC + MVP + ARCH + PLAN READY，制品进仓，无提前写码）  
- [ ] （推荐）完整通过含 Diff 哨兵  

**当前基线（2026-07-28）：** 包级校验已通过；**真人 Agent 会话试跑仍待勾选。**

---

## D. 运行约定（必须）

- [ ] 未批 Spec 禁止写业务代码（违规则回滚）  
- [ ] 热修可跳 A/B，**不可跳 C**  
- [ ] 不做 Agent 自动合 main / 自动发生产  
- [ ] Spec / INTENT 工作副本进仓路径约定（如 `docs/specs/`）

---

| 项 | 填写 |
|----|------|
| 试点团队 | |
| 试点时长 | 例：2 周 |
| 需求类型 | 例：仅 P0 小功能 feature |
| 明确不做 | 例：支付、生产迁移不走试点 Agent 自主 |

- [ ] 试点范围已对相关人可见
