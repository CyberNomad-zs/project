## 1. P3 定位与目标

| 项 | 内容 |
|----|------|
| 期次 | **P3**（约 2～4 周；排在 P0→P1→P2 之后，**不插队**） |
| 运营五维 | **达人是否出单** |
| 三大分析块 | **③ 达人表现**（店铺异常只挂 ①店铺 / ②视频 / ③达人 + 广告/库存横切） |
| 目标 | 联盟中心「表现」可看板 + 异常可出单；店铺下钻到达人；异常域 `达人表现` |
| 现状 | **无表、无采集、无任务台达人页**；投入→是否成交事实层为空 |

成功画像（3 个月，与 P3 相关）：
- 店铺异常可筛选到 **达人表现**
- ③ 联盟表现（达人归因 GMV / 是否出单）门禁通过后有正式表；无数据明示「无数据」
- 运营五维在对应期齐备看板+异常（**不是 P0 做完五维**）

## 3. 前置门禁（必须过才建表）

1. 联盟中心 **数据分析 → 表现**（及达人/所有视频/样品等按需）**可抓**；**达人 ID 稳定**
2. 表现页指标口径可对齐：达人归因 GMV、成交件数、动销达人数、预计佣金、退款等
3. 投入分项可定位来源：
   - **佣金**（表现页预计佣金等）
   - **达人投流花费**
   - **寄样/合作费**
   - 缺项标「**暂不采**」，**禁止填 0**
4. 归因 GMV 与广告系列花费 **不可无脑加总**（文档强制）

门禁失败策略：不建空 schema；停在门禁；UI 显示「无数据」。

## 9. 开放问题（落地前需拍板）

1. **飞书编号**：T5/D4 已被财务/视频占用 → P3 用 T7/D5 还是重定义 T5？
2. **具体 URL / API**：联盟中心域名、表现页 path、XHR 是否可拦截——**POC 未做**
3. **达人 ID**：后台稳定主键是 creator_id / username / 合作 ID？跨店是否全局？
4. **时间粒度**：自然日 vs 窗口快照（P2 content 是窗口锚点）——表现页是哪种？
5. **三类投入来源页**：
   - 佣金：表现页预计佣金？结算页？
   - 达人投流：广告后台？联盟投流专页？与系列 ads 如何拆？
   - 寄样/合作费：样品页？线下表？（飞书已有「达人寄样跟踪表」「达人统计表」「tk达人」人工表痕迹）
6. **表命名统一**：`fact_tiktok_affiliate_*` vs `fact_creator_sample` / 字典 Phase3
7. **合作类型维度**：公开/定向/服务商是否表现页可采
8. **XMind 额外异常**：视频限流、样品履约——P3.0 是否纳入还是后置
9. **与 ① 渠道 GMV「达人带货」**：店日拆解 vs 联盟归因是否对账、以谁为准
10. **阈值签字**：有投入无成交、GMV 下滑、动销降——运营（宋敏）签字流程
11. **采集路线图 P4 vs 经营 P3**：文档批次号对齐，避免实施时找错章节
12. **欧盟 Pop exclude**：联盟域是否沿用 opsExclude（路线图非广告默认排除 Pop/欧盟）
