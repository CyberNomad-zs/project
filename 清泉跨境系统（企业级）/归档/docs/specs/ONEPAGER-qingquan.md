# 清泉跨境系统 · 一页抓重点

> 其他 Spec / MVP / 架构都是展开；**先只看这一页。**

---

## 一句话

**清泉跨境系统 = 让老板看见员工有没有处理异常，并留下「怎么处理的」记录。**  
（不是再做一个跨境 ERP / 数据大屏。）

---

## 只抓这一条主线

```text
异常出现
   → 系统建「案件」
   → 飞书群 @该处理的人（必做）
   → 员工认领 → 填原因 → 关闭
   → 老板看：谁超时、谁没关
   → 全程留痕（以后才做智能推荐）
```

---

## 第一版（MVP）只交 4 样东西

| # | 给谁用 | 是什么 |
|---|--------|--------|
| 1 | 员工 | **工作台**：认领、处理、关闭 |
| 2 | 老板 | **监督台**：未闭环、超时红灯 |
| 3 | 全员 | **飞书群通知**：有事就喊到群并 @人 |
| 4 | 系统里 | **案件 + 时间线**：事和人的过程都存住 |

其余（智能推荐、按级别发个人、Amazon/采购大屏、完整 ERP）= **以后**。

---

## 三个角色，各看一屏

| 角色 | 打开什么 | 只关心 |
|------|----------|--------|
| 运营 | 工作台 | 我的单有没有办完 |
| 老板 | 监督台 | 谁拖着、哪家店积压 |
| 系统 | 飞书群 | 别让人漏看 |

---

## 和市面产品差在哪（记住 3 个字）

1. **盯人**（不是只盯平台数）  
2. **留痕**（人怎么处理写下来）  
3. **自有数据**（原因、误报、结果——平台 API 没有的）
