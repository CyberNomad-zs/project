# 1688 主图 / 视频 / 详情页 设计规范

> 来源：1688 官方诚信通指南 + 平台规则（已联网查证，见文末）。
> 用途：指导 M1 内容生成与后处理。**发布时的硬校验最终以 M3 动态拉取的类目 Schema 为准**——
> 本文件是「怎么画」的设计基线，类目 Schema 是「能不能过」的最终裁判，联调时对齐。
> 代码常量见 `src/generate/specs.py`（本文与该文件保持一致）。

## 一、主图硬规格

| 项目 | 规范 |
|---|---|
| 形状 | **必须正方形**（非正方形扣主图质量分） |
| 尺寸 | 标准 **800×800**；最低 750×750；高清 1200×1200 |
| 放大镜 | ≥700px 才支持悬停放大 |
| 数量 | 上限 **5 张**；至少 3 张实物拍摄图 |
| 单张大小 | ≤ **500 KB** |
| 格式 | JPG / PNG |
| SKU 图 | 800×800 |

## 二、构图与背景

- 产品**占比 50%–75%**，**居中**。
- 背景与产品颜色须明显区分，清晰勾出轮廓。
- **最后一张主图必须纯白底**：RGB **(255,255,255)**，产品居中约占 70%–80%。

## 三、内容红线（违规扣分/降权）

主图**不得出现**：
- 店铺名、主品牌 LOGO、水印、价格
- 促销/夸大文字：秒杀、限时折扣、包邮、正品、第一、最（等极限词）
- 边框、拼接、外网导购信息

例外：若允许放品牌 logo → 仅**左上角**且 **≤200×200px**。

## 四、3:4 长图主图

- 尺寸 **750×1000**。
- 前提：须先设置 **3:4 主图视频** 才能启用。

## 五、主图视频

| 项目 | 规范 |
|---|---|
| 时长 | ≥ **5 秒**（部分类目建议 9–30s） |
| 清晰度 | > **480p** |
| 大小 | ≤ **300 MB** |
| 比例 | 16:9 / 1:1 / 3:4 / 9:16 |
| 禁止 | 全屏水印、与平台无关的 logo/文字 |

## 六、详情页

- PC 端图片宽度 **790px**（窄于 790 右侧留白）。
- 单张高度建议 < **1500px**，保加载速度。
