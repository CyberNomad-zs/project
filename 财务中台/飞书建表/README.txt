飞书财务中台 · 建表文件包
============================================
生成日期：2026-07-07
用途：把「边际利润表 / 现金流月报 / 财务岗任务流」接入现有飞书「财务中台」Base 的第一版建表资料。
说明：这些是可导入飞书的 Excel 种子/模板。飞书里「新建 → 导入 → 从 Excel/CSV」即可生成表。
     导入后字段默认是文本/数字，需按“建表交底单.html”把部分字段改成 单选 / 人员 / 关联 / 公式。

文件清单
--------------------------------------------
[有数据·可直接用]
  01_主数据映射表.xlsx      店铺↔法人↔账户 映射草稿（19行）。★所有关联的锚点，先建。待校对：昇新法人、澜航/创发/智领/圣光归属。
  02_任务目录表.xlsx        19个财务岗任务（频次/类别/交付时间点）。
  03_协作依赖表.xlsx        34行，从14张分解子表抽取的跨部门协作（协同部门/负责人/所需文档/截止日）。
  04_任务步骤SOP.xlsx       147行，各任务的处理步骤（任务编号1/1.1.../产出物）。
  07_月度资金报表_模板.xlsx  资产负债块项目种子（押款/FBA货值/应付货盘等，含来源部门）。

[模板·含表头和示例行]
  05_月度任务实例表_模板.xlsx  ★预填15个每月固定任务（所属月份=2026-07），每月导入后批量改月份即出实例。
                             季度/年度任务另加：所得税申报&缴纳[1/4/7/10月]、VAT申报[2/5/8/11月]、
                             店铺成本[3/6/9/12月末]、工商年检[6月]。展示状态/逾期天数为公式，导入后在飞书加。
  06_利润明细表_模板.xlsx      利润宽表33列（维度+科目明细录入列）。利润桥为公式字段，见交底单§04。
  08_合同收付计划_模板.xlsx    合同分期应收应付子表列头（关联合同表）。
  09_2026任务日历_矩阵.xlsx    19任务×12月 矩阵，✓标注每月该做哪些，含每月合计（各月16条、6月17条、全年193条）。
  10_2026全年任务实例_种子.xlsx ★全年193条实例，一次导入即得12个月全部任务，免每月手动加。

[文档]
  建表交底单.html            ★用浏览器打开。含建表顺序、每张表字段类型、可粘贴的飞书公式、单选选项值、导入步骤。

建表顺序
--------------------------------------------
  ① 主数据映射表（导入01，校对）
  ② 任务流：任务目录(导入02) + 月度实例(05) + 协作依赖(03) + 任务步骤(04)
  ③ 现金流对接：汇率/流水复用现有表；合同表补「收付方向」+合同收付计划(08)；月度资金报表(07)+勾稽
  ④ 边际利润表：导入06宽表，维度关联①，利润桥用交底单§04公式

已锁定的4项口径
--------------------------------------------
  1. 汇率：美元/英镑/欧元/港元 4币种；CNH按1:1；无日元
  2. 合同表：补「收付方向」单选 + 「合同收付计划」子表(08)
  3. 利润「其他项目」= 其他收入+退税收入+税金收入+情趣利润+黑猫利润
                     − 其他支出−提款手续费−中转费−操作费−快递罚款
  4. 主数据映射：按01草稿，仅昇新法人待补
