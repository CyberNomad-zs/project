## 三、关键决策(已定)

1. **主图必须精确还原真实产品**，不允许 AI 重画产品(货要对板)。
2. 每商品 **5 张主图** = 2白底(非生成保真) + 2场景(grok) + 1纯白底(强制)。
3. grok 生成必须用**强制保真 prompt**(保持产品外形一致，只改背景)。
4. 图源核对策略：**视觉配对为主 + 海报裁图兜底**(prompt须聚焦判别特征)。
5. 当前先做 **12个装饰灯泡**(有锚点)；37个台灯待画册页锚点方案。

## 四、关键发现(避坑)

1. **图源文件夹是"系列变体合集"**，不是单品 —— 盲选会货不对板，必须OCR型号核对。
   - 装饰灯泡: 有单型号参数海报作锚点 → 解析器可靠。
   - 便携/台灯(占71%): 标签只在多型号网格图里 → 现解析器返回none，待用画册页锚点。
2. **grok 视觉配对**能区分细微变体，但 prompt 必须点明判别特征(如灯丝形状)，泛泛比会误判。
3. **zapi 生视频契约与交接文档§7-A3不符**: image传字符串、seconds传字符串、仅i2v。
4. **环境**: 主用 Python 3.14；但 **M4/Playwright 用 `.venv-m4`(Py3.12)**，且需 VC++运行库(已装)。
5. **商品数据837个"page_XXX.png"是画册整版跨页截图**(多产品网格)，不是单品图。
