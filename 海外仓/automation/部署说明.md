# 部署说明（给同事）

一份从零到能跑的安装 + 使用指引。系统：Windows 10/11。
> 更新 2026-07-09：新增一键启动器 `启动.bat`；真跑改用环境变量开关（不再手动改文件）；快递方规则改为「渠道末段 = 单一快递方」。

---

## 1. 安装 Python 3.12
- 官网 https://www.python.org/downloads/ 下载 3.12.x，安装时**务必勾选 "Add python.exe to PATH"**。
- 装完打开 PowerShell 验证：`python --version`（应显示 Python 3.12.x）。

## 2. 安装依赖
在 `automation` 目录里打开 PowerShell（地址栏输 `powershell` 回车），执行：
```powershell
# ① pip 用清华源装依赖（不加 -i 会从海外 PyPI 下载，实测仅几 KB/s，极慢）
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
# ② Playwright 用国内 npmmirror 源下浏览器内核（约 300MB，必须！加镜像约 1~2 分钟）
$env:PLAYWRIGHT_DOWNLOAD_HOST = "https://cdn.npmmirror.com/binaries/playwright"
python -m playwright install chromium
```
> 也可以直接双击 `启动.bat` 选 `[8] 安装/更新依赖` 一步完成（**已内置上面两个国内镜像**，无需手动加）。
> 若想让 pip 以后永久走镜像：`pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple`。

## 3. 确认账号配置
打开 `secrets.py` 核对 ERP / WMS 账号密码（金猫 JMSM、黑猫 JMCAT、ERP 手机号账号）。
> ⚠️ 此文件含明文密码，勿外传、勿上传网盘/仓库。

## 4. 一键启动器

> 🖼 **图形界面版（更好看，推荐）**：双击 **`美化启动器.bat`** 打开窗口版启动器——按钮式，
> 绿=安全 / 红=真跑(不可逆) / 蓝=工具，点按钮在新控制台里跑，功能与下面的命令行菜单完全一致。
> 真跑按钮会弹窗要求输入大写 `YES` 二次确认。喜欢命令行的继续用 `启动.bat` 也行（两者等价）。

**命令行版：双击 `启动.bat`**，出现菜单，输数字回车即可：

| 选项 | 用途 |
|---|---|
| `[1]` | 登录 ERP（手动过滑块，首次 / 会话失效时用） |
| `[2]` | **空跑核对**（安全，不真实下单/发货，先跑这个） |
| `[3]` | **登录 + 真实发货**（真跑推荐，一步到位；会红字二次确认，需输入 `YES`） |
| `[4]` | 真实发货（已登录时直接跑） |
| `[5]` | 跟踪号常驻拉取（每 10 分钟，`Ctrl+C` 停） |
| `[6]` | 发货循环常驻（每 5 分钟一轮真跑，只下单+发货，`Ctrl+C` 停） |
| `[A]` | **全流程循环常驻**（每 30 分钟：下单+发货+拉跟踪号+**确认发货**，真跑，会红字二次确认输 `YES`，`Ctrl+C` 停） |
| `[8]` | 安装/更新依赖（首次用一次） |
| `[9]` | 打开日志文件夹 |

> **`[6]` 与 `[A]` 的区别**：`[6]` 发货循环只做「下单+发货」，不收尾；`[A]` 全流程循环每轮多做「拉跟踪号 + 成功标签确认发货（扣库存/提交平台，不可逆）」，是完整一条龙常驻。想常驻自动跑完整流程用 `[A]`。
> **先空跑核对**：`[A]` 是真跑。首次建议先用 `[2]` 空跑核对一遍完整流程（`[2]` 现在也含收尾的干跑），或命令行 `python full_loop.py`（默认空跑循环）观察几轮再上 `[A]`。

> **真跑安全机制**：默认永远是安全空跑（`config.DRY_RUN=True`）。启动器的真跑选项通过临时设环境变量 `HWC_DRY_RUN=0` 开启真跑，**只对那一次运行生效、不改任何文件**——不会出现「改了 DRY_RUN 忘了改回、下次误真跑」的坑。
> 手动真跑（不用 bat）：PowerShell 里 `$env:HWC_DRY_RUN='0'; python run_shipping.py`。

## 5. 手动分步（等价于启动器，供排查用）

### 5.1 首次：手动登录一次 ERP（关键）
ERP（赛狐）登录有**图形验证码 + 腾讯滑块**，无法全自动，需人工过一次，之后会话可复用（约 10 分钟过期，有活动即续期）：
```powershell
python capture/erp_manual_login.py
```
浏览器里手动登录（账号/密码/验证码/滑块），看到 `>>> 检测到已登录！` 即成功。
> WMS 无验证码，脚本用 `secrets.py` 自动登录，无需手动。

### 5.2 空跑演练（安全，不会真发货）
```powershell
python run_shipping.py       # 默认 DRY_RUN=True，只筛选/勾选/统计/定位，不真下单发货
```
看日志：ERP 会话有效、各渠道筛选数量、账号映射、WMS 每渠道选的快递方是否正确。

### 5.3 真实发货
会话约 10 分钟过期，**先登录、再立刻跑**：
```powershell
python capture/erp_manual_login.py      # 登录
$env:HWC_DRY_RUN='0'; python run_shipping.py   # 10 分钟内真跑
```

### 5.4 获取跟踪单号（可长期常驻）
发货后跟踪号要过一会儿才回传，用独立脚本每 10 分钟拉一次（三方仓→待更新→手动更新）：
```powershell
python status_update_loop.py         # Ctrl+C 停止
```

## 6. 快递方规则 —— 渠道末段 = 单一快递方（见 `rules.py`）

ERP「全部渠道」每个渠道名编码了「账号 + 快递方」，**一一对应**：

| ERP 渠道 | WMS 账号 | WMS 改的快递方 |
|---|---|---|
| 昇新海外仓-BLACKCAT-RM / -DPD / -EH | 黑猫 JMCAT | RM / DPD / EH |
| 昇新海外仓-昇新海外仓-RM / -DPD | 金猫 JMSM | RM / DPD |

- **按渠道串行闭环**：ERP 该渠道物流下单 → WMS 对应账号把这批单改成**该渠道末段那一个快递方** → 批量发货 → 失败留存 → 下一个渠道。
- **不轮转、不换快递方**：某渠道用其对应快递方发货失败的单，一律留存提醒、人工跟进（快递方由渠道定死）。
- 渠道列表 = `rules.py` 的 `CHANNEL_ORDER`；新增/调整渠道在此维护。

---

## 7. ⚠️ 注意事项

- **覆盖率缺口**：脚本只处理 `CHANNEL_ORDER` 里列出的渠道。若「待处理」里有列表外渠道（FEDEX / 未知渠道）的单，会被**漏发**。真跑前建议核对待处理各渠道分布，把该自动化的渠道补进 `CHANNEL_ORDER`，其余人工处理。
- **WMS 残留单**：正常情况下 WMS「未发货」列表应只有刚下单的这批；若有历史残留单，会被本批一起改快递方发货，需先清理/隔离。
- **会话 TTL 短（~10 分钟）**：真跑前先登录、10 分钟内跑完；别把时间耗在分步探针上。

## 8. 日志在哪看
- `logs/run_YYYYMMDD.log`：人类可读日志（带 INFO/WARN/ERROR）。
- `logs/events_YYYYMMDD.jsonl`：结构化审计流水，一行一条，记录每笔物流下单/发货/跟踪号结果，用于对账。
- `logs/failures_YYYYMMDD.txt`：失败订单留存（库存不足 / SKU 未配对 / 发货失败）。

### 8.1 运行汇总推送飞书
每次运行 / 每轮循环结束，自动发一张"运行汇总"卡片到飞书群，人在飞书里就能看到本次
空跑/真跑、各渠道结果、成功/失败数、失败订单、耗时。三个入口（`run_shipping.py` 单次、
`shipping_loop.py` 发货循环、`status_update_loop.py` 跟踪号循环）都会推送。
卡片颜色：真跑成功=绿、有失败/异常=红、空跑演练=灰，一眼可辨。

**当前用法：群自定义机器人 Webhook（已配好）**
1. 在飞书目标群：设置 → 群机器人 → 添加"自定义机器人" → 复制它的 Webhook 地址。
2. 把地址填进 `secrets.py` 的 `FEISHU["webhook"]`（已填好当前这个）。
3. 双击 **`测试飞书.bat`**（或命令行 `python notify.py`），收到一张绿色"连通测试"卡片即成功。
   - 若创建机器人时勾了"签名校验"，把密钥填 `FEISHU["webhook_secret"]`。
   - 若设了"自定义关键词"，确保关键词能匹配（卡片标题已含"海外仓"）。
> 换群/换机器人：到那个群重新加自定义机器人，把新 Webhook 地址替换进 `FEISHU["webhook"]` 即可。

**备选：企业自建应用方式**（想发给指定个人、或不想用群机器人时）
在 `FEISHU` 里 **留空 `webhook`**，改填 `app_id`/`app_secret`，再跑 `python notify.py`
会列出机器人所在群及 `chat_id`，回填到 `receive_id`（详见 `secrets.py` 内注释）。

开关与调节（都在 `secrets.py` 的 `FEISHU`，也可用环境变量覆盖）：
- `enable`：`False` 或环境变量 `HWC_FEISHU_ENABLE=0` 可临时关掉通知。
- `level`：`all`=每次运行都发汇总（默认）；`fail_only`=只在有失败/异常时才发（发货循环嫌吵可设它）。
- 网络：脚本**直连飞书优先、系统代理兜底**，国内部署机直连即可；不填 / 填错也不影响发货
  （通知模块全程容错，任何异常只记一条日志、绝不中断主流程）。

## 10. 常见问题
- **`python` 不是内部命令**：Python 没加进 PATH，重装勾选 "Add to PATH"。
- **`playwright install` 慢/失败**：网络问题，重试；或设代理。
- **ERP 会话失效**：重新 `python capture/erp_manual_login.py`（或启动器 `[1]`）登录。
- **空跑/真跑「会话失效中止」**：会话过期了，重登一次再跑。
- **详细业务流程/异常处理**：见上级目录《操作手册_海外仓订单发货.md》。
